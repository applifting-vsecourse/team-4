## User story

Jako pořadatel chci rozlišovat účastníky, vedoucí, hosty a personál, abych mohl pro různé typy osob uplatnit odlišnou cenu a pravidla.

## Kontext

Feature [F08 — Typy účastníků](coverage.md), epic Přihlášky. Usnadňuje registraci a správu přihlášek k akcím.

## Akceptační kritéria

- [ ] V detailu přihlášky je viditelný uložený typ osoby z podporovaných typů: účastník, vedoucí, host a personál.
- [ ] Po volbě typu se zobrazí cena a pravidla příslušná tomuto typu a vybraným termínům.
- [ ] Po uložení přihlášky zůstávají typ a odpovídající cena dostupné ve správném detailu.
- [ ] Bez nastavených cen a pravidel pro typ pořadatel vidí chybějící nastavení; aplikace nepředstírá nulovou cenu.
