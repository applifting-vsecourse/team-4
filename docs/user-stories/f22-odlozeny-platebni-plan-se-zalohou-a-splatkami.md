## User story

Jako účastník chci vidět zálohu, doplatek a splátky s termíny na jednom místě, abych věděl, kdy a kolik mám zaplatit.

## Kontext

Feature [F22 — Platební plán akce](coverage.md), epic Platby. Zpřehledňuje platební povinnosti a jejich vypořádání. Zamítnuto; mimo MVP, neimplementovat.

## Akceptační kritéria

- [ ] V případné budoucí implementaci účastník u své přihlášky vidí jednotlivé položky plánu s částkou a termínem.
- [ ] Pořadatel a účastník vidí stejný plán příslušné přihlášky.
- [ ] Když plán není nastavený, detail nepředstírá existenci zálohy nebo splátek.
- [ ] Bez plánu se zobrazí, že plán není nastavený; běžný přehled celkové úhrady zůstává dostupný.
