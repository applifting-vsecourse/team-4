## User story

Jako pořadatel chci nastavit odlišné otevření registrace podle věkové skupiny, abych mohl řídit přihlašování jednotlivých skupin v různých časech.

## Kontext

Feature [F09 — Věková pravidla registrace](coverage.md), epic Přihlášky. Usnadňuje registraci a správu přihlášek k akcím.

## Akceptační kritéria

- [ ] Když pořadatel uloží odlišné časy otevření pro dvě skupiny, v nastavení vidí časy přiřazené správným skupinám.
- [ ] Před otevřením příslušné skupiny nelze její přihlášku odeslat a návštěvník vidí termín otevření.
- [ ] Po otevření skupiny je její platná přihláška přijatelná bez nutnosti ručního otevření pořadatelem.
- [ ] Pokud nejsou věkové skupiny nakonfigurované, pořadatel vidí, co musí nastavit.
