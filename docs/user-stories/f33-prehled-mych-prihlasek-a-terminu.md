## User story

Jako účastník chci vidět své přihlášky, termíny a stav účasti i úhrady, abych se orientoval v aktuálních přihlášeních.

## Kontext

Feature [F33 — Moje přihláška](coverage.md), epic Přehledy. Zpřístupňuje aktuální údaje pro účastníky a rozhodování pořadatele.

## Akceptační kritéria

- [ ] Po přihlášení účastník vidí pouze své přihlášky a u každé vybrané termíny správné akce.
- [ ] Detail přihlášky ukazuje aktuální stav účasti a informaci o úhradě odděleně; zaplaceno není zaměněné s potvrzenou účastí.
- [ ] Po rozhodnutí pořadatele nebo změně platby se zobrazí stejný aktuální stav jako v pořadatelském detailu.
- [ ] Účastník může otevřít odpovídající přehled plateb.
- [ ] Bez přihlášek portál sdělí, že nejsou žádné přihlášky, a nabídne katalog akcí.
