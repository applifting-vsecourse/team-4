# User stories

[GitHub issues](https://github.com/applifting-vsecourse/team-4/issues) are the single source of truth for story requirements, acceptance criteria and approval. Read and update the corresponding issue, subject to PM authorization in [CLAUDE.md](../../CLAUDE.md).

Markdown stories (`f*.md`), the coverage report and `docs/sprints/*/stories/` are private local PM working material. They are ignored by Git and are not available in fresh clones. Existing local copies are preserved when untracked in this change. Do not commit them or treat them as authoritative.

The import script, manifest and labels remain as PM tooling. Import requires explicit PM authorization and local story files; never use a local copy to overwrite newer issue requirements. The importer is not part of the normal implementation workflow.

See the [Sprint 2 issue index](../sprints/sprint-2/story-index.md). Historical Git revisions may still contain Markdown copies.
