## User story

Jako návštěvník chci vidět příklady různých použití akc.io, abych pochopil, že se platforma nezaměřuje pouze na kempy.

## Kontext

Feature [F60 — Ukázka typů podporovaných akcí](coverage.md), epic Landing page. Představuje platformu a vede návštěvníka k dalšímu kroku.

## Akceptační kritéria

- [ ] Landing page uvádí různé příklady využití odpovídající výběru typů akcí, například tábor, soustředění, firemní výjezd nebo letní škola.
- [ ] Prezentace zřetelně ukazuje širší zaměření platformy a nevyžaduje existenci skutečné veřejné akce každého typu.
- [ ] Znění neslibuje plnou funkční podporu všech ukázaných typů, pokud v MVP není dostupná.
- [ ] Prázdný datový stav se nepoužije: příklady jsou prezentační obsah, nikoli seznam skutečných akcí.
