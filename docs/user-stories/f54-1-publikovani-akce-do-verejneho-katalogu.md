## User story

Jako pořadatel chci řídit veřejné publikování akce, aby návštěvníci viděli pouze akce určené pro veřejnost.

## Kontext

Feature [F54 — Veřejný výpis akcí](coverage.md), epic Katalog akcí. Pomáhá návštěvníkům najít akci a přejít k registraci.

## Akceptační kritéria

- [ ] Oprávněný pořadatel vidí stav publikování akce a může podle nastavené politiky akci publikovat.
- [ ] Publikovaná akce se objeví ve veřejném katalogu; nepublikovaná v katalogu vidět není.
- [ ] Nepublikovanou akci nelze zobrazit jako veřejný detail použitím přímého odkazu.
- [ ] Pokud nejsou publikované akce, katalog uvede, že nejsou dostupné žádné veřejné akce.
