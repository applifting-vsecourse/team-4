# [S2-06] Otevření registrace a přímý odkaz

Stav: **NÁVRH — bez označení READY**, k týmové kontrole.

Produktový rozsah schválen PM; připravenost k implementaci posoudí PM samostatně.

## User story

Jako organizátor chci otevřít nebo zavřít přihlašování a zkopírovat odkaz na formulář, abych mohl řídit příjem přihlášek.

## Kontext

Sprint 2 podle [zadání a rozhodnutí](../README.md). Původní produktové požadavky: [#66](https://github.com/applifting-vsecourse/team-4/issues/66). Tato story neuzavírá automaticky původní issues.

## Navigační kontext

Podle [sitemapy](../../../sitemap.md) a [rozhodnutí sprintu](../README.md); jde o umístění funkce, nikoli rozšíření rozsahu nebo předpis samostatných stránek.

- Umístění: Správa akce → Nastavení akce → Otevření registrace; Veřejná část → Detail akce / Přihláška na akci.
- Přístup: Organizátor nastavuje vlastní akci; návštěvník otevírá její veřejný odkaz.
- Přechody: Organizátor zkopíruje přímý odkaz → veřejná stránka podle stavu akce → při otevření formulář S2-07. Katalog není potřeba.

## Akceptační kritéria

- [ ] U akce organizátor získá odkaz a může jej zkopírovat.
- [ ] Odkaz v nepřihlášeném prohlížeči otevře formulář správné akce s jejími termíny a cenami.
- [ ] Odkaz neobsahuje přístup k pořadatelským údajům ani seznamu přihlášek.
- [ ] Neexistující akce zobrazí srozumitelný nedostupný stav bez cizích dat.

- [ ] Nová akce je koncept. Organizátor ručně otevře přihlašování až po doplnění údajů akce, alespoň jednoho termínu, účtu a počtu dní splatnosti; pokoje nejsou podmínkou otevření.
- [ ] Organizátor může přihlašování zavřít; existující přihlášky a jejich přístup zůstávají zachované.
- [ ] Koncept a zavřená akce nepřijímají nové přihlášky ani z dříve otevřeného formuláře; server odmítne odeslání a stránka vysvětlí stav.

- [ ] Odkaz na koncept zobrazí pouze „Akce není dostupná“, bez údajů akce.
- [ ] Po uzavření veřejná stránka zachová název, popis, místo a termíny s cenami, ale místo formuláře zobrazí „Přihlašování je uzavřené“.
- [ ] Po znovuotevření funguje stejný odkaz; zamčení údajů od prvního otevření zůstává.
- [ ] U tlačítka prvního otevření je upozornění „Otevřením přihlašování zamknete název, popis, místo, termíny a ceny.“ Další potvrzovací dialog se nezobrazuje.

## Mimo rozsah
