# akc.io frontend

React and Vite with TanStack Router/Query, Tailwind, shadcn/ui, Lucide, ky, Zod and BetterAuth.

## Structure

- `src/routes`: file-based routes, including home, login, signup and an authenticated dashboard placeholder.
- `src/features`: feature APIs, schemas, hooks and components; includes authentication.
- `src/components`: shared components and the UI kit.
- `src/styles/global.css`: semantic tokens, neutral light/dark palettes and shared styles.
- `src/test`: Vitest setup.

`src/routeTree.gen.ts` is generated by the router plugin during Vite development/build. Use Zod at API boundaries and TanStack Query for server state.

## Commands

Run from the repository root:

```sh
pnpm frontend dev
pnpm frontend type-check
pnpm frontend test:ci
pnpm frontend build
```

The frontend runs at http://localhost:3050 and builds to `build`. See the [root README](../../README.md) for full setup. Browser-visible environment variables use the `VITE_` prefix and are baked in at build time. Define akc.io design requirements in [DESIGN.md](../../DESIGN.md).

## End-to-end tests and PO demo

Playwright scenarios in `e2e/` drive the real app: frontend, backend and database. Locally they reuse the running dev servers (`pnpm dev`); in CI Playwright starts them.

```sh
pnpm frontend exec playwright install chromium  # once
pnpm frontend test:e2e        # headless, as in CI
pnpm frontend test:e2e:ui     # Playwright UI mode: steps, time travel, watch
pnpm frontend demo            # walkthrough for the PO: pauses after every step
pnpm frontend demo:autoplay   # the same walkthrough without pauses
```

`demo` opens a visible, slowed-down browser, captions each step in the page and types visibly. After each step it stops in the Playwright Inspector; press Resume (F8) to continue. `DEMO_SLOWMO=600` changes the speed. Scenarios mark their steps with `step()` and fill fields with `type()` from `e2e/support/demo.ts`.
